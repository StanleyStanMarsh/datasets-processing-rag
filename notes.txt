data_enrichment_oracle.py:
Скрипт формирует датасет для обучения моделей информационного поиска путем строгого майнинга сложных негативных примеров (hard negatives) на основе трех объединенных CSV-файлов с вопросами и ответами по кибербезопасности. Для каждого вопроса вычисляются эмбеддинги с помощью SentenceTransformer, после чего через FAISS осуществляется поиск ближайших ответов; кандидат считается валидным сложным негативом только если его сходство с запросом превышает порог относительно позитивного ответа (с учетом EPSILON) и одновременно превосходит сходство позитивного ответа с кандидатом на величину DELTA, что реализует геометрически осознанный отбор. В итоговый набор для каждой записи включаются вопрос, корректный ответ, один случайно выбранный валидный сложный негатив и один случайный легкий негатив, а также значения попарных косинусных сходств, после чего результат сохраняется в CSV-файл с выводом статистики покрытия.

dataset_enrichment_qa_mining.py:
Скрипт формирует обогащенный QA-датасет для обучения моделей поиска путем майнинга сложных негативных примеров на основе семантической близости вопросов, используя эмбеддинги модели FALCON и индекс FAISS для эффективного поиска соседей. Алгоритм находит вопросы, семантически близкие к исходному, и использует ответы на эти похожие вопросы в качестве сложных негативных примеров. Это означает, что hard negative здесь — это ответ на другой, но очень похожий вопрос. Для каждой записи также генерируется легкий негатив путем случайной выборки, после чего итоговый набор с колонками question, answer, hard_negative и negative сохраняется в CSV-файл.

dataset_enrichment.py:
Скрипт обогащает объединенный QA-датасет по кибербезопасности путем добавления сложных и случайных негативных примеров для каждой пары вопрос-ответ, используя модель FALCON и FAISS-индекс с метрикой L2, построенный исключительно на эмбеддингах ответов. Алгоритм кодирует сами ответы и для каждого вопроса ищет ответы, которые семантически близки к правильному ответу на этот вопрос, но не совпадают с ним. Здесь hard negative — это ответ, который выглядит похоже на правильный (по векторному представлению текста ответа), но является неверным для данного конкретного вопроса. легкий негатив выбирается случайно из всех ответов за исключением истинного и уже выбранного сложного. Итоговый набор сохраняется в CSV-файл с четырьмя колонками: question, answer, hard_negative и negative.

qwen_as_a_judge.py:
Скрипт выполняет автоматическую оценку качества пар «вопрос-ответ» из датасетов AttackQA и CybersecurityQAA, используя локальную LLM (Meta-Llama-3-8B-Instruct через vLLM) в роли экспертного судьи. Для каждой пары формируется промпт с критериями фактической точности, полноты и релевантности, требующий от модели ответа в формате JSON с обоснованием и вердиктом («yes», «no» или «uncertain»), который затем парсится с многоуровневым фолбэком для устойчивости к ошибкам формата. Перед оценкой данные фильтруются по признаку человеческого происхождения или экспертной проверки, после чего для выборки до 400 примеров на каждый датасет вычисляются метрики согласия, неопределенности и селективности, а детальные результаты и агрегированная статистика сохраняются в CSV и JSON соответственно.

save_local_model.py:
Скрипт загружает предобученную модель all-MiniLM-L6-v2 из репозитория Hugging Face Hub и сохраняет её полный снимок (веса, конфигурацию и токенизатор) в локальную директорию ./models/all-MiniLM-L6-v2 для последующего офлайн-использования.

test_base_model.py:
Скрипт оценивает качество базовой кросс-энкодерной модели `ms-marco-MiniLM-L6-v2` на обогащенном датасете с триплетами (вопрос, позитивный ответ, сложный негатив, легкий негатив), вычисляя метрики ранжирования MRR@3 и NDCG@3. Для каждого примера модель скорингует все три кандидата относительно запроса, после чего на основе полученных оценок и бинарных меток релевантности рассчитываются индивидуальные значения метрик, которые затем усредняются по всему набору данных для получения итоговой производительности.

train_cross_encoder_ranknet.py:
Скрипт выполняет дообучение кросс-энкодера `ms-marco-MiniLM-L6-v2` на парах «вопрос–позитивный ответ» и «вопрос–сложный негатив» с использованием функции потерь RankNet, которая минимизирует `softplus(s_neg - s_pos)` для обеспечения более высокого скоринга релевантных документов. В процессе обучения модель оптимизируется через AdamW с линейным расписанием и клиппингом градиентов, при этом после каждой эпохи вычисляются тестовые потери и точность ранжирования, а также отслеживается возможное переобучение. По завершении скрипт сохраняет настроенную модель, токенизатор, историю метрик в CSV и график динамики потерь в указанную выходную директорию.

train_cross_encoder.py:
Скрипт выполняет дообучение кросс-энкодера `ms-marco-MiniLM-L6-v2` на триплетах (вопрос, позитивный ответ, сложный негатив, легкий негатив) с использованием кастомной функции потерь OrderedTripletLoss, которая через взвешенную комбинацию softplus-штрафов обеспечивает строгое упорядочивание скорингов: позитив выше легкого негатива, позитив выше сложного негатива и сложный негатив выше среднего арифметического позитива и легкого негатива. Обучение включает разделение данных на train/test, оптимизацию AdamW с линейным расписанием и клиппингом градиентов, а также мониторинг трех специфических метрик ранжирования и тестового лосса после каждой эпохи для контроля переобучения. По завершении скрипт сохраняет настроенную модель, токенизатор, историю потерь в CSV и график динамики обучения в целевую директорию.
